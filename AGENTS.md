# Haul 'Er Back Trailers public site — repository instructions

## Purpose
Static trailer marketing, models, pricing, licensing checklist, and customer-financing information. The README documents a local preview from `public/` using `python3 -m http.server 8080`.

## Public-content rules
- Do not publish investor names, funding sources, capital totals, budget allocations, or funding-based payback calculations.
- Clearly separate published trailer/unit pricing from estimates and unverified claims.
- Keep licensing and buyer-financing descriptions accurate and updated from actual requirements; do not invent lender approvals or financing terms.
- Do not publish private prospective customer data or unpublished commercial arrangements.

## Development and release
Inspect all relevant site pages before changing pricing or financing copy. Preview static pages locally, verify links, and test mobile rendering when possible. Publishing through GitHub Pages or changing domains requires explicit authorization. Record what was verified versus merely drafted.
