# Haul 'Er Back Trailers — public site

Static marketing site for **Haul 'Er Back Trailers** (Ottawa enclosed trailers).

- Landing / waitlist, models, pricing (unit costs & rent-based break-even), licensing checklist
- Custom domain: `haulerbacktrailers.dustinnstroud.com`
- GitHub Pages: publish from the repo root (`main`)

## Local preview

```bash
python3 -m http.server 8080
```

## Content rules (owner)

- Do **not** publish investor names, funding sources, capital totals, budget allocations, or funding-based payback figures on this site.
- Per-unit costs, prices, margins, and rent-based break-even in trailers/month are OK.
- Licensing checklist stays on the site.
