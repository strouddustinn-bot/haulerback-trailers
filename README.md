# Haul 'Er Back Trailers — public site

Static marketing site for **Haul 'Er Back Trailers** (Ottawa enclosed trailers).

- Landing / waitlist, models, pricing (unit costs & rent-based break-even), licensing checklist
- Custom domain: `strouddustinn-bot.github.io/haulerback-trailers`
- **GitHub Pages:** publish the `public/` folder (or set Pages source to `/` if this repo root *is* the site)

## Local preview

```bash
cd public && python3 -m http.server 8080
```

## Content rules (owner)

- Do **not** publish investor names, funding sources, capital totals, budget allocations, or funding-based payback figures on this site.
- Per-unit costs, prices, margins, and rent-based break-even in trailers/month are OK.
- Licensing checklist stays on the site.


## Customer financing

Public page: [financing.html](financing.html). Business-plan section: [business-plan.md](business-plan.md) / [business-plan.html](business-plan.html).

This is **buyer** financing via third-party lenders (Financeit, Prefera, LendCare, National Bank Equipment Finance, LeaseLine, Canada Powersports Financing). It is not company funding. Do not add investor names, capital sources, or funding-based payback figures to this site.
